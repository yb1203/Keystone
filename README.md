# 🔐 Keystone

极简、私密的个人密码管理器。**Docker 一键部署**，零知识加密，自托管 —— 所有数据都掌握在你自己手里。

> Keystone（拱心石）：建筑里承重的那块中心石。你的主密码，就是撑起整个密码库的拱心石。

## ✨ 功能

**条目管理**
- 🔒 **零知识加密**：主密码 → scrypt 派生密钥 → AES-256-GCM 加密所有字段；服务端只存密文，密钥仅存在于内存，重启即自动锁定
- 🃏 **卡片式首页**：分类筛选、收藏、搜索（命中高亮）、排序（最近更新/名称/创建时间）
- 📝 **自定义字段**：字段名+值完全自定义，类型可选 **文本/密码/网址/数字/布尔/日期/邮箱**
- 📌 **卡片配置**：字段可置顶到首页卡片（最多 4 条，可展开全部）、可开关复制按钮
- — **分割线分组**：多个同类型账号（如 3 个 QQ）可用分割线在卡片上分组显示
- 🏷 **分类管理**：完全手动创建，支持重命名（自动同步条目）、删除、标签云展示
- 🖼 **图标**：上传图片作为卡片图标（自动压缩，未设置则显示分类色首字）
- 📎 **附件**：上传证件/截图等，加密存储，支持图片/PDF/文本**预览**
- 🎲 **密码生成器**、一键复制、自动锁定

**安全**
- 🔑 **两步验证（TOTP）**：可选开启，解锁需主密码 + 动态验证码，带 8 个一次性恢复码，扫码添加
- 🔑 **修改主密码**：全量重加密（含附件），当前会话无缝切换
- 🛡 **解锁限流**：连错 5 次封禁 1 分钟
- ⏱ **自动锁定时长**：设置页可调（1~240 分钟）

**备份**
- 💾 **导出/导入**：单文件加密备份（含条目、附件、图标、两步验证配置），全新部署可直接恢复
- 💾 **自动备份**：每天自动备份到 `data/backups/`，保留最近 7 份

## 🚀 快速开始（Docker 部署）

```bash
# 1. 构建并启动（在项目目录下）
docker compose up -d --build

# 2. 打开浏览器
#    http://你的服务器IP:3000

# 3. 首次访问设置主密码
#    ⚠️ 主密码无法找回，务必牢记！忘记 = 数据永久丢失
```

数据保存在 Docker 卷 `vault-data` 中（`/app/data/`），容器删了数据也还在。

**公网访问强烈建议加 HTTPS**：用 Caddy / Nginx 反代到 3000 端口，并设置环境变量 `VAULT_HTTPS=true`、`VAULT_TRUST_PROXY=true`。仅内网使用可跳过。

## 💻 本地运行

需要 Node.js 20+：

```bash
npm install
npm start          # 默认 http://localhost:3000
```

## ⚙️ 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `3000` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `DATA_DIR` | `./data` | 数据目录（vault.json + attachments/ + backups/） |
| `VAULT_AUTO_LOCK_MINUTES` | `30` | 闲置自动锁定默认值（分钟，设置页可改） |
| `VAULT_UNLOCK_MAX_ATTEMPTS` | `5` | 解锁最大失败次数 |
| `VAULT_UNLOCK_LOCKOUT_SECONDS` | `60` | 失败封禁时长（秒） |
| `VAULT_ATTACH_MAX_MB` | `20` | 单个附件大小上限（MB） |
| `VAULT_BACKUP_KEEP` | `7` | 自动备份保留份数 |
| `VAULT_HTTPS` | `false` | 部署在 HTTPS 反代后时设为 `true`（Cookie Secure + HSTS） |
| `VAULT_TRUST_PROXY` | `false` | 反代后设为 `true`（解锁限流才能看到真实 IP） |

## 🛡 安全模型

| 威胁 | 防护 |
|---|---|
| 数据文件被拷贝 | 全部字段 AES-256-GCM 加密，只有密文 |
| 离线暴力破解 | scrypt（128MiB 内存成本）+ 认证加密 |
| 网络嗅探 | 生产必须 HTTPS |
| 暴力破解解锁 | 限流：5 次失败封禁 1 分钟 |
| 主密码泄露 | 可选两步验证（TOTP） |
| 浏览器 XSS | 输出全量转义 + CSP 头 |
| 上传恶意文件 | 附件加密存储、强制下载不内联、预览限制类型 |

**架构说明**：本项目是"服务端加密"架构 —— 主密码在解锁时发送给服务器，解密密钥存在于服务器内存。服务器被完全攻破时，解锁状态下可读取明文（与 Bitwarden 的浏览器端加密不同）。对自托管、单用户场景是合理取舍。

**部署安全清单**
- [ ] 公网访问必须 HTTPS（`VAULT_HTTPS=true` + `VAULT_TRUST_PROXY=true`）
- [ ] 主密码 ≥ 12 位，大小写+数字+符号，不与任何其他密码重复
- [ ] 建议不要存银行卡密码 / CVV（合规风险）
- [ ] 定期导出加密备份到离线位置

## 💾 数据备份

- **推荐：界面「导出」** → 下载单个加密备份文件（**含条目、附件、图标、两步验证配置**，不含主密码），存到安全位置
- **恢复**：已初始化时顶栏「导入」（有覆盖确认）；**全新部署**时创建界面点「已有备份？从备份恢复」
- 恢复后请用**备份对应的主密码**解锁
- 服务端每天自动备份到 `data/backups/`，保留最近 7 份（可配 `VAULT_BACKUP_KEEP`）

## ❓ 常见问题

**忘记主密码怎么办？**
无法找回，只能删除数据重新初始化。这是设计如此 —— 服务器端不存储任何可恢复主密码的信息。

**可以多用户使用吗？**
不能。这是个人单用户工具。多人场景请用 Vaultwarden / Bitwarden。

**为什么不用数据库？**
单用户个人场景 JSON 文件 + 原子写入完全够用，换来零原生依赖、镜像极小、备份就是复制文件。

**忘记验证器 App 怎么办？**
用启用两步验证时保存的**恢复码**解锁（每个只能用一次）；恢复码也丢了只能删除数据重来。
